# Css Crash Course

## Overview
Intensive CSS training covering layouts, flexbox, grid, and responsive design

## Contents

* **Module 1: CSS Basics & Box Model**
  * Selectors, Specificity, and Cascading
  * Colors, Typography, and Formatting
  * Margin, Padding, Borders, and Box-Sizing
* **Module 2: Layouts & Positioning**
  * Normal Flow, Block vs. Inline elements
  * Position property (Static, Relative, Absolute, Fixed, Sticky)
  * Z-index and Stacking Contexts
* **Module 3: Flexbox Mastery**
  * Flex Container properties (`display: flex`, `flex-direction`, `justify-content`, `align-items`)
  * Flex Item properties (`flex-grow`, `flex-shrink`, `flex-basis`)
* **Module 4: Grid Layouts**
  * Grid Container setups (`grid-template-columns`, `grid-template-rows`, `gap`)
  * Grid Areas, `minmax()`, and `repeat()` functions
* **Module 5: Responsive Web Design**
  * Media Queries and Mobile-First Approach
  * Fluid Typography and Relative Units (`rem`, `em`, `vw`, `vh`)


## Learning Objectives
  * **Master Layout Techniques**: Build modern, complex layouts using Flexbox and CSS Grid.
  * **Implement Responsive Design**: Create mobile-first, adaptive web pages using Media Queries and relative units.
  * **Understand the Box Model**: Efficiently control element sizing, spacing, and positioning without unintended layout breaks.
  * **Write Maintainable CSS**: Apply standard naming conventions and manage selector specificity to avoid style conflicts.

## Notes
 * Always use `box-sizing: border-box;` in a global reset to simplify layout calculation.
 * Prioritize **Flexbox** for one-dimensional layouts (rows *or* columns) and **CSS Grid** for two-dimensional layouts (rows *and* columns simultaneously).
 * Use relative units (`rem`, `em`) for typography and padding/margin to maintain accessibility across client font-size preferences.
