# Frontend Development Fundamentals & Interview Prep

A structured repository containing study notes, coding solutions, and key concept breakdowns covering frontend engineering, modern web technologies, and technical interview preparation.

---

## 📁 Repository Structure

```text
.
├── 00-frontend-content-index/   # Learning roadmap and study guide
├── 01-web-dev-fundamentals/     # Core building blocks of the web & browser architecture
├── 02-html-crash-course/        # Semantic HTML, accessibility (a11y), and DOM structure
├── 03-css-crash-course/         # Flexbox, Grid, animations, and modern styling
├── 04-javascript-crash-course/  # Modern JS (ES6+), async patterns, DOM manipulation, OOP
├── 05-react-crash-course/       # Components, state management, hooks, and lifecycle
├── 06-interview-questions/      # Coding problems, implementation challenges, & solutions
└── 07-frontend-quiz/            # Practice exams and knowledge check assessments
```

---

## 📚 Modules Overview

| Module | Description | Focus Areas |
| :--- | :--- | :--- |
| **00. Frontend Content Index** | Roadmaps and structured index for the learning path | Learning goals, topics checklist |
| **01. Web Dev Fundamentals** | Essential protocols and web concepts | HTTP/HTTPS, DNS, client-server model, browser rendering |
| **02. HTML Crash Course** | Core markup concepts for web applications | Semantic elements, forms, SEO, accessibility (a11y) |
| **03. CSS Crash Course** | Layout engines and styling strategies | Box model, Flexbox, Grid, responsiveness, specificity |
| **04. JavaScript Crash Course** | Core language principles & modern syntax | Closures, prototypes, `async/await`, event loop, DOM API |
| **05. React Crash Course** | Modern UI development with React | JSX, hooks (`useState`, `useEffect`), props, state, virtual DOM |
| **06. Interview Questions** | Practical coding and frontend UI challenges | System design, API integrations, custom component builds |
| **07. Frontend Quiz** | Practice quizzes to test concept retention | Theoretical concepts, code output predictions |

---

## 🚀 How to Use

1. **Follow the Modules:** Start with `01-web-dev-fundamentals` and progress sequentially through HTML, CSS, JS, and React.
2. **Review Notes & Code:** Each folder contains markdown documentation along with code snippets and standalone examples.
3. **Practice Interview Problems:** Navigate to `06-interview-questions` to solve hands-on coding challenges.
