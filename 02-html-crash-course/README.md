# HTML Crash Course

## Overview

Comprehensive HTML training covering semantic structure, forms, media integration, and accessibility best practices.

## Contents

* **Module 1: HTML Basics & Document Structure**
  * Doctype, `<html>`, `<head>`, and `<body>` breakdown
  * Headings (`<h1>`-`<h6>`), Paragraphs, and Text Formatting
  * Unordered, Ordered, and Description Lists
* **Module 2: Links & Media Elements**
  * Hyperlinks (`<a>`), paths (relative vs. absolute), and targets
  * Images (`<img>`), Audio (`<audio>`), and Video (`<video>`)
  * Embeds and Frames (`<iframe>`)
* **Module 3: Semantic HTML5 & Accessibility**
  * Structuring elements (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`)
  * Alt text, ARIA roles, and document outline
  * Keyboard navigation and standard DOM hierarchy
* **Module 4: Forms & Input Handling**
  * Form elements (`<form>`, `<label>`, `<input>`, `<textarea>`, `<select>`)
  * Input types (text, email, password, number, radio, checkbox)
  * Form validation attributes (`required`, `pattern`, `min`, `max`)
* **Module 5: Tables & Metadata**
  * Table structure (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`)
  * Meta tags for viewport, character set, SEO, and social sharing (Open Graph)

## Learning Objectives

* **Master Semantic Web Architecture**: Structure web pages using meaningful HTML5 tags to improve readability and SEO.
* **Build Accessible Interfaces**: Ensure web content meets accessibility standards for screen readers and keyboard users.
* **Construct Functional Forms**: Design interactive forms with user input validation and accessible labeling.
* **Embed & Manage Media**: Seamlessly integrate optimized images, audio, video, and external media into web layouts.

## Resources

* [MDN Web Docs - HTML](https://developer.mozilla.org/en-US/docs/Web/HTML) — Comprehensive HTML standards and element documentation.
* [W3C HTML Accessibility Guidelines](https://www.w3.org/WAI/fundamentals/accessibility-intro/) — Essential principles for creating accessible HTML structure.
* [web.dev - Learn HTML](https://web.dev/learn/html) — Modern guide to structuring content effectively.

## Notes

* Always pair `<label>` elements with `<input>` tags using the `for` and `id` attributes to guarantee screen reader compatibility.
* Use semantic elements like `<main>`, `<nav>`, and `<article>` instead of generic `<div>` tags wherever applicable.
* Always supply descriptive `alt` text for images; use `alt=""` for purely decorative images.
